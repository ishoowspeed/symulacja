# Discord Clone - Fioletowy Motyw + Neon.tech + Render.com

Pełnowymiarowy klon Discorda z czatem w czasie rzeczywistym i trwała bazą danych.

## Funkcje:
- Rejestracja i logowanie użytkowników.
- Fioletowy motyw inspirowany aplikacją Discord.
- Czat tekstowy w czasie rzeczywistym (WebSocket).
- Trwałe przechowywanie kont i historii wiadomości w bazie **Neon.tech**.
- Gotowy do darmowego wdrożenia na **Render.com**.
